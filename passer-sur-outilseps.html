Vos données ne basculent pas toutes seules

Classes, élèves, notes et réglages sont enregistrés sur chaque adresse séparément. Si vous avez déjà travaillé sur l’ancienne version, il faut exporter puis importer votre sauvegarde pour les retrouver sur outilseps.fr.

Quelle est votre situation ?

Choisissez votre cas : le guide détaillé s’affiche ci-dessous. Vous pouvez aussi ouvrir directement outilseps.fr.

Première visite

  1. Ouvrez outilseps.fr dans votre navigateur.
  2. Utilisez Outils EPS comme d’habitude : aucune manipulation particulière.
  3. Sur téléphone ou tablette, vous pourrez ajouter l’application web à votre écran d’accueil (voir l’onglet « J’utilise l’application »).

Repère visuel : sur outilseps.fr, l’icône est verte.

Transférer vos données

Faites cette manipulation une fois : exportez ici vos données de l’ancienne adresse, puis sur outilseps.fr installez d’abord l’application web, puis importez votre copie.

Sur l’ancienne adresse

clemp-app.github.io/outilsEPS

Téléchargez une copie de vos données (classes, élèves, réglages…) sur votre appareil.

Sur outilseps.fr

outilseps.fr

1. Installer l’application web

Ajoutez Outils EPS à votre écran d’accueil depuis outilseps.fr. L’icône est verte — c’est le repère pour savoir que vous êtes sur la bonne version.

iPhone / iPad
  1. Ouvrir Safari → outilseps.fr
  2. Partager → Sur l’écran d’accueil
Android
  1. Ouvrir Chrome → outilseps.fr
  2. Menu (⋮) → Installer l’application
Ouvrir outilseps.fr

2. Importer vos données

Une fois l’application installée, importez le fichier exporté à l’étape de gauche.

  1. Ouvrir l’icône verte Outils EPS (ou outilseps.fr)
  2. Menu (☰) → Sauvegarde
  3. Importer une sauvegarde
  4. Choisir le fichier que vous venez d’exporter
Ouvrir Sauvegarde sur outilseps.fr

Remplacer l’application sur votre écran d’accueil

Si vous aviez ajouté Outils EPS à l’écran d’accueil depuis l’ancienne adresse, créez une nouvelle icône verte depuis outilseps.fr. Ce n’est pas une application du magasin d’apps : c’est une application web que vous ajoutez au navigateur.

iPhone / iPad
  1. Ouvrez Safari et allez sur outilseps.fr
  2. Appuyez sur Partager
  3. Choisissez Sur l’écran d’accueil
  4. Ouvrez ensuite l’icône verte Outils EPS

Vous pouvez supprimer l’ancienne icône bleue de l’écran d’accueil.

Android
  1. Ouvrez Chrome et allez sur outilseps.fr
  2. Menu (⋮) → Installer l’application ou Ajouter à l’écran d’accueil
  3. Ouvrez l’icône verte Outils EPS

Si vous aviez des données dans l’ancienne application, exportez-les d’abord (onglet « J’ai des données »).

Installer depuis outilseps.fr
