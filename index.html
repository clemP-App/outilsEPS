    À propos d’Outils EPS

    Application locale

    Outils EPS fonctionne sur votre appareil, sans compte et sans envoi de données vers un serveur. Les pages et les outils sont enregistrés localement pour un usage hors ligne une fois chargés.

    Installer sur l’écran d’accueil

    Vous pouvez ajouter l’application à l’écran d’accueil pour y accéder comme à une appli :

    • iPhone (Safari) : bouton Partager, puis « Sur l’écran d’accueil ».
    • Android (Chrome) : menu du navigateur, puis « Installer l’application » ou « Ajouter à l’écran d’accueil ».
    • Ordinateur (Chrome / Edge) : icône d’installation dans la barre d’adresse, si proposée.

    Vos données

    Classes, dispenses, championnats, etc. sont stockées dans la base locale de l’appareil (IndexedDB). Elles ne sont pas synchronisées entre plusieurs appareils.

    Vous pouvez perdre ces données si vous videz les données du site, effacez le cache ou l’historique du navigateur, désinstallez l’application, ou changez d’appareil. Pensez à exporter régulièrement une sauvegarde JSON via le bouton 💾 en haut à droite.
