Sauvegarde et restauration

💾 Où sont stockées vos données ? Stockage local, risques et bonnes pratiques

Outils EPS enregistre vos classes, cahier de texte, championnats, réglages… directement sur ce téléphone ou cet ordinateur. Rien n’est envoyé automatiquement sur internet et vous n’avez pas besoin de créer un compte.

En pratique, cela veut dire que…

  • Vos données ne suivent pas toutes seules si vous changez d’appareil.
  • Si vous videz le cache du navigateur ou supprimez l’icône de l’app, tout peut disparaître.
  • Si l’appareil est perdu ou cassé sans copie de sauvegarde, les données sont perdues.

Pourquoi exporter avant tout ?

L’export télécharge un fichier outilsEPS-backup.json : une copie complète de vos données, à garder dans un endroit sûr (Drive, iCloud, mail…). C’est votre filet de sécurité avant un import ou une synchronisation.

Importer ou synchroniser ensuite

  • Importer — restaure un fichier exporté sur cet appareil ou un autre (fusion avec l’existant ou remplacement complet).
  • Synchroniser — aligne deux appareils à vous (ex. téléphone et tablette) via QR code. Ouvrez cette page sur les deux, lancez la sync ; une connexion internet est nécessaire le temps du transfert.

À part : les réponses remontées par QR code depuis les outils élèves (débrief, musculation…) se gèrent dans l’outil Données élèves, pas sur cette page.

Comment procéder

  1. 1 Exportez d’abord une copie de vos données pour être sûr de ne rien perdre.
  2. 2 Ensuite, selon votre besoin : importez une sauvegarde ou synchronisez deux appareils.

Confidentialite et RGPD

La synchronisation cree une session temporaire protegee par un jeton affiche uniquement dans le QR code. Supabase ne recoit les sauvegardes que le temps de comparer et fusionner les deux appareils. Aucune conservation volontaire n'est faite apres validation ou fermeture de session.

Le QR code impose une action physique entre les deux appareils. Sans ce jeton, une autre personne ne peut pas recuperer la sauvegarde. Pour rester conforme, utilisez cette fonction seulement avec vos appareils et une connexion de confiance.
