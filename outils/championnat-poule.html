Gestion

Les matchs sont organisés par journée : chaque équipe joue au plus une fois par tour, pour un déroulement équilibré sur le terrain. L’ordre des appariements suit l’ordre d’ajout des équipes (méthode du cercle).

    Classement

    3 pts victoire, 1 pt match nul, 0 défaite. Tri : pts → différence → marqués → nom.

    Matchs

    Saisissez les scores par journée ; le classement se met à jour automatiquement lorsque les deux scores d’un match sont renseignés.
