    Outils EPS — Élèves

    Page élèves

    Cette page ne liste que les outils utilisables par les élèves en séance (compteurs, vitesse, débrief, etc.). Votre professeur peut vous envoyer le lien ou un QR code pour y accéder directement.

    Les données saisies dans un outil restent sur votre appareil, sauf si vous partagez un résultat au prof via QR (débrief, journal de musculation…).

    Installer sur l’écran d’accueil

    • iPhone (Safari) : Partager → « Sur l’écran d’accueil ».
    • Android (Chrome) : menu → « Ajouter à l’écran d’accueil ».

    Partager aux élèves

    Affichez ce QR code ou copiez le lien : les élèves arrivent sur cette page, sans les outils réservés au professeur.
